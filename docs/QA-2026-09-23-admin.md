## Defects

### P1

1. FIXED (d770a29). `/settings` crashed ("Application error", digest
   2696003168) whenever a shop's `credentials` is `{}` (staging's disarmed
   shops, any shop without a sealed envelope): `Buffer.from(undefined)` in
   `lib/db/credentials.ts`. Now reads as not connected. Also guards the Gmail
   and print credential readers.
2. OPEN. No way to create a VA account from the UI (only
   `npm run create-user`). Needed for rollout (6 VAs). Plan: admin-only
   "Add VA" drawer on /designers, same pattern as `addDesigner`.
3. OPEN. No way to deactivate a designer (or VA) from the UI; a departed
   designer keeps their login and stays on the auto-assign roster. Also note:
   sessions are JWT, so a deactivated user's existing session stays valid until
   it expires (security lane).

### P2 (open)

4. Settings > Customer Email: the stage email auto-send switch
   (`businesses.stage_email_auto_send`) has no UI at all; only the sending
   switch is shown, and its OFF state is not explained (only the "turning on
   skips stale emails" note).
5. Settings > Email templates: after "Reset to default" the badge stays
   "Customized" and the fields keep the edited text until a reload
   (`TemplateCard` keeps `useState` from first render). "Save template" gives
   no confirmation. Repro: open Order received, edit subject, Save, wait,
   Reset, the old edited text is still shown; reload shows Default.
6. No Business card in Settings (name, logo). `businesses.logo_url` is shown
   on the customer upload and proof pages but can only be set in the database;
   PixArt has none on staging.
7. Server-rendered times show in UTC on Vercel with no zone: System Health
   ("Last run 23 Sept, 7:31 am" for a 5:31 pm AEST run), and the same missing
   `timeZone` in payouts, customers, orders table, board, print queue
   (`Intl.DateTimeFormat("en-AU", {...})` without `timeZone`; `TZ` in
   `lib/home/shared.ts` is Australia/Melbourne).
8. Settings > Portrait Styles lists 0 styles for both shops while the setup
   checklist says "Styles configured, 4 styles" (shop-offered styles vs
   /styles catalog); confusing on day one.

### P3

9. Hydration mismatch (React #418) on /settings, /orders, /emails: dates
   formatted with `toLocaleString()` / `DateTimeFormat(undefined)` differ
   between server (en-US, UTC) and browser (en-AU, AEST). Files:
   `components/settings/etsy-shop-card.tsx:78`,
   `components/settings/shopify-shop-card.tsx:135`,
   `lib/integrations/sync-health.ts:16`, `components/qc/version-strip.tsx:7`,
   `components/orders/new-order-form.tsx:66`.
10. /health took 34 s on the first load (cold); later loads about 3 s.
11. The sidebar has both "Designers" (boards, /board) and "Designer Roster"
    (/designers); easy to mix up.
